# Optimal Tree Converting

The project represents AND/INV circuits as DAGs and matches subcircuit truth tables against a cell library.

- learning Python and algorithms

# Problem

Find a mapping that reduces `cost = wA × A + wP × P + wD × D`.

- **A, P, D** : Area, Leakage power, Delay
- **wA, wP, wD** : Arbitrary weight 


## Input

- **wA, wP, wD** : Arbitrary weight 
- **library.json**: Cell library with three cost metrics (area, leakage_power, delay)

        {
            "AND2_X1": {
                "inputs": [ "A1", "A2" ],
                "outputs": [ "ZN" ],
                "area": { "value": 1.064, "unit": "um^2" },
                "functions": { "ZN": "(A1 & A2)" },
                "leakage_power": { "value": 25.066064, "unit": "nW" },
                "delay": { "value": 0.040499869641781594, "unit": "ns" },
            },
            "AND2_X2": ...

- **{circuit}.json**: a combinational circuit DAG

        # example
        {
            "inputs": [
                {"name": "a", "node": 1}, ...
            ],
            "outputs": [
                {"name": "y", "edge": 2}, ...
            ],
            "nodes": [
                {"op": "CONST_0", "name": "const_zero", "value": false, "input": [], "output": []}, ...
            ],
            "edges": [
                {"source": 1, "target": 3, "port": 0}, ...
            ]
        }

## Output

- **{circuit}_opt.json**: Result of optimal Covering

        # same format with "{circuit}.json"

# Approach

1. **Candidate search** — Traverse backward from the outputs using DFS. Merge AND/INV truth tables into subcircuits with at most six boundary inputs, keeping shared nodes as mapping boundaries.
2. **Cell matching** — Match candidates to library cells by input count and truth table. Boundary order determines the cell's input pin order.
3. **Cost evaluation** — Normalize cell metrics by their library maxima. Add each cell's area and leakage to the summed boundary costs, and its delay to the maximum boundary delay.
4. **Selection and memoization** — Apply candidate normalization in `getOptCircuit()` and select the lowest weighted score. Store the selected cell, boundaries, and accumulated metrics in `dp`; revisited nodes reuse the selection and act as boundaries.
5. **DAG reconstruction** — Follow selected cells from the outputs to build the mapped circuit, reusing shared nodes.

The mapping is heuristic and stores one selection per node; global optimality is not guaranteed. Candidate normalization currently compares lists instead of per-metric extrema and remains a TODO.

# File Structure

```text
optimal-tree-converting/
├── reference/               # External originals: Nangate .lib and EPFL .aig
├── input/                   # Derived JSON and input schematics
├── output/                  # Mapped JSON and schematic snapshots
├── utiles/                  # Directory name as used in this repository
│   └── symbols/             # (generated by AI) Gate symbols and previews
│   ├── lib2json.py          # (generated by AI) Liberty → cell JSON
│   ├── module2json.py       # (generated by AI) AIGER/BLIF → circuit DAG JSON
│   ├── makeGraph.py         # (generated by AI) Selected candidates → mapped DAG
│   ├── circuit_metrics.py   # (generated by AI) Area, leakage, and longest-path evaluation
│   ├── graph2dot.py         # (generated by AI) DOT/SVG schematics
│   ├── render_graphviz.cjs  # (generated by AI) Optional Graphviz WASM helper
├── Cell.py                  # Cell functions, truth tables, cost normalization
└── main.py                  # DFS candidate search, selection, experiments
```

# Reference Sources
- `reference/module/adder.aig` and `log2.aig`: the [EPFL Combinational Benchmark Suite](https://github.com/lsils/benchmarks). Both match the published files in `arithmetic/` byte for byte.
- `reference/library/NangateOpenCellLibrary_typical.lib`: the typical corner of the Nangate Open Cell Library. Its contents match the [OpenROAD distribution](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts/blob/master/flow/platforms/nangate45/lib/NangateOpenCellLibrary_typical.lib) after normalizing line endings.
